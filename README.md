Gobble Dash — The Great Turkey Escape: a side-scrolling runner where a turkey auto-runs 3000 m through four stages (Farmyard, Barn, Kitchen, Forest) while a farmer closes in. Jump, duck, grab golden feathers for a shield, and reach the forest before three stumbles get you caught. Canvas 1280x720, seeded RNG, deterministic shots, WebAudio synth sounds.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
